Quick Install (One Time)

  1. 1
    Open this page in Zen Browser or Firefox and click Install Chess Helper above.
  2. 2
    When the browser prompt appears, click Continue to Installation → Add.
  3. 3
    Pin Chess Helper to your toolbar, open a bot game or analysis board on Lichess or Chess.com, and switch it On.
  4. 4
    Automatic updates: New versions install automatically in the background—no need to download anything again.

Modes & Learning Tools

Best Move Mode

Clean, distraction-free mode showing Stockfish’s single strongest move arrow on your turn, paired with an optional side Evaluation bar and adjustable depth (8–18).

Coach Mode (Mix & Match)

  • Opponent threat: Red dashed arrow showing their immediate threat.
  • Piece hint first: Highlights the piece to move without spoiling the square.
  • Top 3 moves: Green, blue, and amber candidate arrows (MultiPV).
  • Expected reply: Dotted orange arrow for the opponent’s best answer.
  • Move feedback: Instant Best / Good / Inaccuracy / Mistake / Blunder badge.

Keyboard Shortcuts

Toggle overlay on / off Alt + Shift + C
Reveal move in Piece Hint mode Alt + Shift + H
Fair Play Notice: Chess Helper is a visual learning overlay (it never clicks or auto-moves pieces). Use it against bots, on puzzles, or for study—not in rated live games against humans.
