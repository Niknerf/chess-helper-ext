# Chess Helper — Firefox & Zen Browser

Real-time **Stockfish 19 WASM** analysis overlay, evaluation bar, and customizable **Coach** learning mode for **Chess.com** and **Lichess.org**.

## 1-Click Install (v1.2.0)

Open the install page in **Zen Browser** or **Firefox**:

**[Install Chess Helper](https://niknerf.github.io/chess-helper-ext/)**

### How it works
1. Open **[https://niknerf.github.io/chess-helper-ext/](https://niknerf.github.io/chess-helper-ext/)** in Zen Browser or Firefox.
2. Click **Install Chess Helper (v1.2.0)** → **Continue to Installation** → **Add**.
3. Pin **Chess Helper** to your toolbar and toggle it **On** on Lichess or Chess.com.
4. Future releases update automatically in the background via `updates.json`.

## Features
- **Best Move Mode**: Draws Stockfish's strongest move arrow on your turn.
- **Coach Mode**: Toggle any combination of **Opponent threat**, **Piece hint first** (`Alt+Shift+H` to reveal), **Top 3 moves**, **Expected reply**, and **Move feedback** badges.
- **Evaluation Bar**: Optional side panel synced to board orientation.
- **100% Local & Private**: Runs Stockfish 19 WASM directly inside the browser with zero external servers and zero data collection.

## Keyboard Shortcuts
- `Alt+Shift+C` — Toggle overlay on / off
- `Alt+Shift+H` — Reveal full move arrow in Piece Hint mode

> **Fair Play Notice**: Visual learning overlay only (never clicks or auto-moves). Please use against bots, on puzzles, or for post-game study.
