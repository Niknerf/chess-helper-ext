Chess Helper

Local Stockfish 19 WASM analysis overlay, evaluation bar, and Coach mode for Chess.com and Lichess.org. Runs 100% in your browser and updates automatically.

Install Chess Helper (v1.2.0)
How to install (one time):
  1. Open this page in Zen Browser or Firefox and click the button above.
  2. Click Continue to Installation → Add in the browser prompt.
  3. Pin Chess Helper to your toolbar. Future versions install automatically!

Intended for bot games, puzzles, and post-game study. Please respect fair-play rules in live rated games.
